# OOP Assignment

A comprehensive repository containing all 11 Java Object-Oriented Programming (OOP) practical assignments, complete with source code, descriptions, and execution output screenshots.

## 🛠️ Requirements & Compilation

### Prerequisites
- **JDK (Java Development Kit)**: JDK 8 or higher (Note: Practical 11 uses Applet which is supported on JDK 8).
- **Git**

### How to Compile and Run
Navigate to any practical directory and compile using `javac`:
```bash
cd Practical-1
javac MatrixMultiplication.java
java MatrixMultiplication
```
